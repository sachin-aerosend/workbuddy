You're halfway through something and think "I need to call them back in 15 minutes." If setting that reminder takes more than a few seconds, you won't do it, and you'll forget.

Here are five ways to set a quick reminder on Windows 11, with the pros and cons of each.

## 1. The Clock app's timer

Windows 11's built-in **Clock** app has a Timer tab.

1. Press the **Windows key**, type *Clock*, open it.
2. Go to **Timer**, pick or edit a timer (for example 15 minutes) and press play.
3. When it ends, you get a notification with a sound.

- **Good:** built in, reliable, works offline.
- **Not so good:** a timer has no message, so "15 minutes" might leave you wondering *what* it was for. Rename the timer if you use it often.

## 2. Clock app alarms

For a specific time ("at 4:30"), use the **Alarm** tab in the same app. You can name alarms, which fixes the "what was this for?" problem.

## 3. Microsoft To Do reminders

If you already keep a to-do list, **Microsoft To Do** lets you add a task with a reminder time. Your reminder carries its own context: the task title *is* the message.

- **Good:** reminders sync to your phone if you use To Do there.
- **Not so good:** a few more clicks than a timer; you need a Microsoft account.

## 4. Calendar reminders

For anything tied to a meeting or deadline, a calendar event with a reminder (Outlook or Google Calendar) is the most dependable: it shows up on every device. It's overkill for "check the oven in 10 minutes", but perfect for "send the proposal before 5pm".

## 5. Sticky Notes (for things you need to see)

Windows **Sticky Notes** don't ring, but a bright note on your screen works for "don't forget" items that aren't tied to a time. Pair one with a timer for the best of both.

> A good rule: if it's about *time* ("in 10 minutes"), use a timer or reminder. If it's about *attention* ("don't forget X today"), put it somewhere you'll see it.

## A more fun option: ask the cat

I wanted "remind me in 10 minutes to call Priya" to take two seconds, so I built it into WorkBuddy. Right-click the cat, choose **Set a reminder**, type the message and tap **10 min**.

- A tiny alarm clock floats above the cat with a live countdown.
- When time's up, it rings, the cat jumps, and you get a Windows notification with your message.
- You can **snooze 5 minutes** or mark it done, and reminders survive restarts.

:::cta

## Which one to use?

- **"In 10 minutes":** Clock timer, or right-click the cat.
- **"At 4:30":** Clock alarm.
- **"Before the deadline":** calendar reminder.
- **"Sometime today":** To Do, or a sticky note.

The best reminder system is simply the one that's fast enough that you actually use it.
